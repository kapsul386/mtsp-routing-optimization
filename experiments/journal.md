# Журнал экспериментов

## Текущая исследовательская линия

Сравниваем baseline-эвристики и более сильные методы для `mTSP` по критерию `MINSUM` при фиксированном лимите времени.

## Базовые методы

- `rand+nn`
- `2opt+greed`

## Методы для проверки гипотезы

- `grasp`
- `lkh-wrapper` после интеграции

## Что нужно фиксировать в каждом запуске

- инстанс и его размерность;
- число коммивояжеров;
- алгоритм и параметры;
- лимит времени;
- значение `MINSUM`;
- время работы;
- комментарии по стабильности результата.

## Текущие артефакты пайплайна

- генератор инстансов: `experiments/generate_mtsp_instances.py`;
- конфиг эксперимента: `experiments/config.json`;
- пакетный прогон: `experiments/run_benchmarks.py`;
- сырые результаты: `data/results/mtsp_results.csv`;
- агрегированная сводка: `data/results/mtsp_summary.csv`.
