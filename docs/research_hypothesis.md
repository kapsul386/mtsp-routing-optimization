# Рабочая гипотеза исследования

Основная гипотеза курсового проекта:

При решении задачи множественного коммивояжера (`mTSP`) в условиях жесткого ограничения на время вычислений до 60 секунд эвристики, которые сочетают построение начального решения и последующее локальное улучшение, дают лучшее значение целевой функции `MINSUM`, чем простые базовые стратегии.

## Практическая формулировка для экспериментов

В рамках репозитория гипотеза будет проверяться через сравнение:

- baseline-методов `rand+nn` и `2opt+greed`;
- более сильных подходов `grasp` и `LKH-based` метода после интеграции.

## Что нужно показать экспериментально

- преимущество по `MINSUM` при одинаковом временном бюджете;
- устойчивость преимущества на задачах разной размерности;
- влияние числа коммивояжеров на относительную эффективность методов.
